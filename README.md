# Portfolio — Mohamed Merhbene

Site statique (HTML/CSS/JS, sans dépendance), bilingue FR / EN.

## Voir en local

Ouvre `index.html` dans le navigateur, ou :

```bash
python3 -m http.server 8000   # puis http://localhost:8000
```

## À compléter

- `index.html` : remplace `TON_EMAIL@exemple.com` par ton e-mail.
- Ajoute ton CV en PDF à la racine sous le nom `cv.pdf` (bouton « Mon CV »).
- Section « Parcours » : ajoute tes stages, expériences et certifications LinkedIn (voir le commentaire `TODO`).

## Mettre en ligne gratuitement (GitHub Pages)

1. Crée un dépôt nommé `merhbben.github.io` et pousse ce dossier dedans.
2. Le site est publié sur `https://merhbben.github.io`.
