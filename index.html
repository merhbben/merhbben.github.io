01À propos

Je suis élève ingénieur en Cybersécurité & Cloud Engineering à ESPRIT. J'aime les projets où le code rencontre un vrai problème : planifier l'agriculture d'un pays, gérer la flotte d'une agence de location, contrôler les stocks d'un restaurant ou faire tourner une pâtisserie.

Je travaille sur toute la chaîne, avec la sécurité intégrée dès le départ : authentification et rôles, modélisation des données, API, modèles d'optimisation et de prévision, puis déploiement conteneurisé dans le cloud avec Docker et CI/CD.

  • ◆Sécurité dès la conception : authentification, rôles, audit, secrets hors du code
  • ◆Des données traçables : chaque chiffre a sa source
  • ◆Architecture propre en couches, code testé
  • ◆Pensé pour l'utilisateur réel : mobile, RTL, multilingue

TuniNō チュニ農

Deux nations, une vision : l'agriculture durable.

Plateforme de planification agricole inspirée de WAGRI (Japon), pour deux publics. Le Ministère de l'Agriculture suit le bilan national, planifie la production par culture, gouvernorat et saison, et simule des scénarios. L'agriculteur importe ou dessine son terrain, puis le moteur AgroBrain le découpe en parcelles optimisées.

  • Lecture de plans par vision par ordinateur (OpenCV, OCR ONNX)
  • Optimisation des cultures avec OR-Tools, irrigation FAO-56 planifiée par CP-SAT
  • Prévisions XGBoost / LightGBM avec backtest, données FAOSTAT, World Bank, NASA POWER
  • Dimensionnement solaire et batterie, chambre froide de contre-saison simulée heure par heure
  • Interface bilingue Français / derja tunisienne (RTL), PostGIS, Docker
